# College Seminar Registration System

A Java-based desktop application for managing college seminars, speakers, student registrations, and participant statistics.

## Overview

This project is being developed as part of a Java Programming assignment. It aims to simplify seminar management through a graphical interface and a relational database.

## Objectives

- Manage students, speakers, and seminars.
- Register students for seminars.
- Prevent duplicate registrations.
- Enforce seminar capacity limits.
- Support registration cancellation.
- Generate participant statistics by department and seminar category.
- Demonstrate object-oriented programming and database connectivity.
